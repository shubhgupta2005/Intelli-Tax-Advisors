API Documentation

Base URL: https://intellitaxadvisors.com/employeeworkspace/expenses

GET /api/expenses
List expenses. Params: project_id, category_id, status, date_from, date_to, search, limit, offset
POST /api/expenses
Create expense. Body: {title, amount, date, project_id, category_id, ...}
PUT /api/expenses/:id
Update expense fields
DELETE /api/expenses/:id
Delete expense and all attachments
GET /api/dashboard?period=30
Full analytics summary
POST /api/expenses/:id/attachments
Upload file attachment (multipart/form-data, field: file)
GET /api/projects, /api/categories
CRUD for projects and categories
Header: X-API-Key: <key>
Pass API key for authenticated access from external systems
